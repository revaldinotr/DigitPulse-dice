## Contributing photos

Photos of an independent build are welcome — especially clear shots of the
CD4017 to CD4075 wiring, which is where most build errors happen and where a
reference image helps more than any description. See
[`../../CONTRIBUTING.md`](../../CONTRIBUTING.md).
